# Руководство пользователя для приложения "Разработка фрагмента информационной системы Туристическая компания"

## Введение
Данное приложение предназначено для управления данными туристической компании и предоставляет доступ к различным функциям для трех типов пользователей: директора, менеджера и клиента. Каждый тип пользователя имеет свои права и возможности, включая выполнение CRUD операций, изменение темы интерфейса, управление паролями и работу с SQL консолью.

---

## Вход в систему
1. Откройте приложение.
2. На экране входа введите свои учетные данные:
   - **Логин**: ваш логин (например, `director`, `manager`, `client`)
   - **Пароль**: ваш пароль
3. Нажмите кнопку "Войти".

---

## Пользовательские роли и права

### 1. Директор
**Права:**
- Полный доступ ко всем таблицам.
- Может изменять таблицы сотрудников и туристических поездок.
- Может просматривать список сотрудников и оформленные ими поездки.
- Может изменить фамилию сотрудника.
- Может удалить клиента.

**Основные функции:**
- Просмотр всех таблиц.
- Вывод списка сотрудников и их поездок.
- Изменение фамилии сотрудника.
- Удаление клиента.

### 2. Менеджер
**Права:**
- Полный доступ к просмотру всех таблиц.
- Может изменять все таблицы.
- Может вывести количество клиентов в каждой туристической группе.
- Может изменить название маршрута.
- Может удалить клиента.

**Основные функции:**
- Просмотр всех таблиц.
- Вывод количества клиентов в туристических группах.
- Изменение названия маршрута.
- Удаление клиента.

### 3. Клиент
**Права:**
- Может просматривать список туристических поездок, маршруты, страны и пункты.
- Не может вносить изменения в данные.
- Может вывести количество маршрутов по странам.
- Может вывести список клиентов.
- Может изменить название пункта.
- Может удалить страну.

**Основные функции:**
- Просмотр списка туристических поездок.
- Просмотр маршрутов и стран.
- Вывод количества маршрутов по странам.
- Вывод списка клиентов.

## Основные функции

### CRUD операции
- **Создание:** Нажмите на кнопку "Добавить" в соответствующем разделе и заполните необходимые поля.
- **Чтение:** Выберите нужный элемент из списка для просмотра его деталей.
- **Обновление:** Выберите элемент и нажмите "Редактировать". Внесите изменения и сохраните.
- **Удаление:** Выберите элемент и нажмите "Удалить". Подтвердите действие.

### Изменение темы
1. Перейдите в раздел "Настройки".
2. Выберите вкладку "Тема".
3. Выберите желаемую тему из доступных вариантов.
4. Нажмите "Сохранить изменения".

### Изменение пароля
1. Перейдите в раздел "Настройки".
2. Выберите вкладку "Изменить пароль".
3. Введите текущий пароль, новый пароль и подтвердите новый пароль.
4. Нажмите "Сохранить изменения".

### Работа с документами
1. Перейдите в раздел "Документы".
2. Для работы с SQL консолью:
   - Нажмите на кнопку "Открыть SQL консоль".
   - Введите SQL-запрос в текстовое поле.
   - Нажмите "Выполнить", чтобы выполнить запрос и просмотреть результаты.

## Часто задаваемые вопросы (FAQ)

### Как восстановить забытый пароль?
Обратитесь к администратору (директору) для сброса пароля.

### Как изменить тему интерфейса?
Перейдите в раздел "Настройки" и выберите вкладку "Тема".

### Какие права у разных пользователей?
- **Директор**: полный доступ, изменение фамилий и удаление клиентов.
- **Менеджер**: просмотр и изменение всех таблиц, удаление клиентов.
- **Клиент**: просмотр данных без возможности изменения.

### Как выполнить SQL запрос?
Перейдите в раздел "Документы", откройте SQL консоль и введите ваш запрос.
